# Письмо для мамы

Мобильная открытка на HTML, CSS и JavaScript. Откройте `index.html` в браузере. Для GitHub Pages загрузите файлы в корень репозитория и выберите **Settings → Pages → Deploy from a branch → main → / (root)**.

В редакторе можно изменить обращение, девять пожеланий, письмо и подпись. На опубликованном сайте текстом можно поделиться ссылкой. Для открытки с фотографией скачайте отдельный HTML-файл и отправьте его получателю. Фотография обрабатывается в браузере и сохраняется внутри скачанного файла. Для повторного редактирования текущего варианта оставьте вкладку открытой.
