# Письмо для мамы

Мобильная открытка на HTML, CSS и JavaScript. Чтобы открыть её локально, скачайте `index.html` и `photo.jpg` в одну папку и откройте `index.html` в браузере.

Для GitHub Pages используйте **Settings → Pages → Deploy from a branch → main → / (root)**. Поделитесь обычным адресом сайта, чтобы отправить эту открытку.
